## 1.	Resumo do Negócio
A Fossa das Marianas (FDM) é uma empresa de vendas de vestuários, com temática aquática e praiana, que possuiu um website obsoleto. Inspirado pelo contato com o produto Pico da Neblina e seu SIOF, necessita de uma implementação customizada para suas necessidades baseadas no SIOF.

## 2.	Objetivo do Sistema
O objetivo do sistema é fornecer todas as ferramentas necessárias para o ciclo de vida de um e-commerce, como ferramentas de busca, processos de início e fim de venda, controle de estoque, visualização de produtos e processamento de compras.
